# Bing 壁纸（极简版）

Windows 托盘小程序：每天自动把必应当日壁纸设成桌面壁纸，随时可以翻上一张 / 下一张。

<sub>需求分析、功能拆解、设计取舍见 [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)</sub>

## 功能

| 操作 | 效果 |
| --- | --- |
| 每天自动 | 后台每 10 分钟检查一次必应是否换图，换了才动你的壁纸（休眠/关机唤醒后会自动补上） |
| 上一张 / 下一张 | 在本地图片库里按日期前后翻，到头时菜单项置灰 |
| 换今天的 | 立刻回到必应当前首页图，也可**双击托盘图标** |
| 清理旧图片 | 删除 30 天前的图片（文件 + 索引一起删），启动时和每天换图后也会自动清一次 |
| 开机自启 | 默认开启，菜单里可勾选/取消（关掉就不会自动换了） |
| 退出 | 菜单最后一项 |

鼠标悬停托盘图标可以看到当前这张图的日期和标题。

## 使用

程序已经装好并正在运行：

```
C:\Users\<你>\AppData\Local\Programs\BingWallpaper\BingWallpaper.exe
```

- 托盘图标默认在任务栏的「隐藏的图标」（`^`）里，可以拖出来固定。
- 重新编译后需要手动覆盖安装目录里的 exe（先右键托盘 → 退出，再覆盖，再启动）。
- **换位置**：把 exe 挪到别处后，在托盘菜单里把「开机自启」关掉再打开一次，让注册表指向新路径。

## 数据位置

```
%LOCALAPPDATA%\BingWallpaper\
├─ images\      下载的壁纸（保留最近 30 天）
├─ index.json   本地库索引：已有哪些图、当前显示到第几张、上次自动换图的时间
└─ log.txt      运行日志（超过 1 MB 自动清空）
```

卸载 = 删掉上面这个目录 + 程序目录，再清掉注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 里的 `BingWallpaper`。

## 从源码构建

```powershell
dotnet build src/BingWallpaper/BingWallpaper.csproj -c Release   # 编译
pwsh tools/publish.ps1                                          # 单文件 exe ≈ 343 KB（需要 .NET 8 桌面运行时）
pwsh tools/publish.ps1 -SelfContained                           # 自包含单文件 ≈ 63 MB，任何机器直接跑
pwsh tools/make-icon.ps1                                        # 改完图标绘制逻辑后重新生成 app.ico
```

产物在 `dist\`。

## 设计要点

- **必应归档只保留最近 8 天**（`idx>7` 会被钳制），所以「上一张」最早只能回到 8 天前，
  再往前要靠本地积累。首次运行会把这 8 天的元数据全部并入本地库，图片先下当天那张，其余后台补齐。
- 判断"今天要不要换"用的是**图片标识（urlbase）**而不是日期字符串：必应在 00:00 前后发布新图，
  只比日期会出现"到了新的一天但必应还没换图，就再也不换"的 bug。`LastAutoKey + LastAutoDate` 两个字段一起用：
  当天已换过 → 跳过（省请求）；没换过且必应图变了 → 才动壁纸。
- 图片按屏幕**物理分辨率**请求 UHD（`uhd=1&uhdwidth=&uhdheight=`），4K 屏拿到的是 3840x2160 而不是 1920x1080；
  程序声明 DPI 感知，避免高缩放屏上取到虚拟化后的尺寸。
- 只调用 `SystemParametersInfo(SPI_SETDESKWALLPAPER)` 换图，**不改** `WallpaperStyle` 注册表，不会覆盖你的"填充/适应"设置。
- 下载先写 `*.tmp` 再原子改名，失败重试 1 次；网络异常只写日志，保留当前壁纸，下一轮（10 分钟后）自动重试。
- 索引里已被必应删除的图（404）会被标记并从库里清掉，翻页时自动跳过，不会卡住。
- **清理**只删「保留期之外的图」和「索引里没引用的孤儿文件」，当前显示的那张有豁免权；
  启动时、每天自动换图后各跑一次，菜单里也能手动触发（手动触发会用气泡告诉你删了几张）。
- 单实例互斥锁，重复启动会静默退出。

## 已知限制

- 用的是必应非官方公开接口，接口变更时程序会失效（表现为日志里一直失败、壁纸不变）。
- **只保留最近 30 天**：超出期的图片连文件带索引条目一起删（4K 屏约 75 MB，1080p 约 10 MB）。
  所以「上一张」最多能翻 30 天。想改保留时长：`src/BingWallpaper/WallpaperService.cs` 里的 `RetentionDays` 常量。
- 当前正在显示的那张永远不删，即使你把它翻出来了。
- 内存占用约 60 MB（.NET WinForms 托盘程序的基础开销）。
